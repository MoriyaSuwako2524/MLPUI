01 Model and job

Model configuration

Defaults work for new models; fine-tuning requires the original architecture.

QM/MM baseline

Two independent models: TensorNet-QMMM uses upstream panxl TensorNet-ext radial MM messages (schema2); tensornet-ext restores the historical QM-only TensorNet + H+3 head (schema1). Both use a nonperiodic, fixed 10 Angstrom MM input set. Only QMMM has an external message cutoff. Units after conversion: Å, eV, e. MM potential is +dE/dQ_MM, not atomic ESP charges. Offline mode requires a matching baseline for every enabled target. Online UMA/charge weights and MD are not connected.
