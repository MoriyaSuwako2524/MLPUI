File mapping and units

Leave blank or use {} to read standard fields automatically. Map only existing fields; {shard} is supported. charges contains atomic charges; charge contains the total charge of each structure.

Delete dataset

By default, only the library record is removed. File deletion is permanent. Files referenced by jobs or other datasets cannot be deleted.

Archiving only hides the library record. Source files and existing jobs are retained.

Create a new split from this dataset

Ratios are relative weights; 0 omits a subset. Separate NPY copies and indices are saved without changing the source. For correlated trajectories, use ordered splits or register separate groups to avoid leakage between adjacent frames.
